\# Skill: Process Files



\## Trigger

When files appear in /Needs\_Action/



\## Steps

1\. Read each .md file in /Needs\_Action

2\. Parse the YAML frontmatter for type, priority, status

3\. Create a Plan file in /Plans with frontmatter, objective, steps with checkboxes

4\. Update Dashboard.md recent activity

5\. Move processed file to /Done



\## Rules

\- Follow Company\_Handbook.md at all times

\- Never delete files, only move them

\- Flag anything over $100 for approval
