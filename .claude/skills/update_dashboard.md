\# Skill: Update Dashboard



\## Trigger

After any action is completed



\## Steps

1\. Read current Dashboard.md

2\. Update: last check time, pending counts, recent activity, alerts

3\. Write updated Dashboard.md



\## Counting

\- Pending Actions = .md files in /Needs\_Action

\- Approvals Waiting = .md files in /Pending\_Approval

\- Tasks Completed Today = .md files in /Done with today's date
