# Company Handbook - Rules of Engagement

## Communication Rules
- Always be polite and professional
- Reply to urgent messages within 2 hours during business hours
- Never send bulk emails without human approval
- Add AI-Assisted signature to all automated emails

## Financial Rules
- Flag any payment over $100 for human approval
- Never auto-approve payments to new recipients
- Log all financial transactions in /Accounting/
- Maximum 3 payment actions per hour

## Social Media Rules
- All social media posts require human approval before publishing
- Keep tone professional but friendly
- No political or controversial content

## File Management Rules
- Never delete files without human approval
- Always move processed files to /Done/
- Log all file operations in /Logs/

## Security Rules
- Never store passwords or API keys in markdown files
- Use environment variables for all credentials
- DRY_RUN mode must be ON during development
- All sensitive actions require human-in-the-loop approval

## Escalation Rules
- If confidence is below 80%, ask for human input
- If an action is irreversible, always require approval
